Help - Supplier Definition

This form allows you to edit supplier details in the system. Follow these steps:

  • Supplier ID: This field is automatically filled and cannot be edited. It represents the unique identifier for the supplier.
  • Supplier Name: Enter the name of the supplier. This field is required and cannot be left blank.
  • Phone Number 1: Enter the primary phone number for the supplier. This field is required and must be a valid 10-digit phone number.
  • Phone Number 2: Enter the secondary phone number for the supplier (optional). It must be a valid 10-digit phone number if provided.
  • Save Supplier Button: Once the supplier details are updated, click this button to save the changes.

Notes:

  • If you wish to exit without saving, click the EXIT button.
  • Ensure that you have entered a valid phone number before saving.
