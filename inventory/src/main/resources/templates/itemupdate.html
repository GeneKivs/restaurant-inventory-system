Help - Edit Item

This form allows you to update the details of an existing inventory item. Follow these instructions carefully:

  • Item ID: This is the unique identifier for the item. It is automatically filled and cannot be edited.
  • Item Name: Update the name of the item if necessary.
  • Category Name: Select the correct category for the item from the dropdown list.
  • Unit Name: Select the unit of measurement for the item from the dropdown list.
  • Reorder Level: Enter the minimum stock quantity at which the system should notify for reordering.
  • Update Item Button: Click this button to save the updated information.

Notes:

  • Ensure that all fields are correctly updated before clicking the update button.
  • If you need to exit without saving changes, click the EXIT button.
