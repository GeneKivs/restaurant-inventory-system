Help - Supplier Edit

This form allows you to edit the details of an existing supplier. Follow these instructions:

  • Supplier ID: This field is automatically filled and cannot be edited. It represents the unique identifier of the supplier.
  • Supplier Name: Enter the name of the supplier. This field is required and cannot be left blank.
  • Phone Number 1: Enter the primary phone number of the supplier. This field is required and must be a valid 10-digit phone number.
  • Phone Number 2: Enter the secondary phone number (optional). If provided, it must be a valid 10-digit phone number.
  • Save Supplier Button: Once you have edited the supplier's details, click this button to save the changes.

Notes:

  • If you wish to exit without saving, click the EXIT button.
  • Make sure all required fields are filled before saving.
