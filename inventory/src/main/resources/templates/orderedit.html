Help - Edit Purchase Order

This form allows you to update the details of an existing purchase order. Follow these instructions carefully:

  • Order ID: This is the unique identifier for the order. It is automatically filled and cannot be edited.
  • Supplier Name: Select or update the supplier for the order from the dropdown list.
  • Order Date: Displays the date the order was created. This field is not editable.
  • Quantity: Enter the correct quantity to be ordered or update the existing quantity if needed.
  • Cancel Order: Check this box if you wish to cancel the order. You must provide a reason if cancelling.
  • Update Order Button: Click this button to save your changes to the purchase order.

Notes:

  • Ensure all information is correct before clicking the Update Order button.
  • If you need to exit without saving changes, click the EXIT button.
  • After updating, you can print the updated order if needed.
