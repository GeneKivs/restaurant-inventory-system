Help - Edit Supplier Item Linkage

This form allows you to edit the linkage between a supplier and an item. Follow these instructions carefully:

  • Supplier ID: This field displays the unique identifier for the supplier-item linkage. It is read-only and cannot be changed.
  • Supplier Name: Select the supplier whose item linkage you wish to edit. This dropdown will show the existing suppliers.
  • Item Name: Choose the item you want to link with the selected supplier. You can select from a list of items that have been previously defined.
  • Save Linkage Button: After selecting both the supplier and the item, click the Save Linkage button to save the updated linkage.

Notes:

  • If you need to exit the form without saving, click the Exit button to return to the previous page.
