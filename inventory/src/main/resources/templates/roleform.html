Help - Role Definition

This form allows you to define new roles for users in the system. The role defines the permissions granted to users. Follow these steps:

  • Role Name: Enter a name for the new role. This could be something like "Admin", "Manager", etc.
  • Permissions: Select the permissions that you wish to assign to this role. Each permission grants the role specific actions within the system.
  • Save Role Button: Once the role name and permissions are selected, click this button to save the new role.

Notes:

  • Make sure to assign the appropriate permissions based on the role's responsibilities.
  • Once saved, the role will be available for assignment to users in the system.
  • If you wish to exit without saving, click the EXIT button.
