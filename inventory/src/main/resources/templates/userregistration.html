Help - User Registration

This form is used to register new users for the admin module. Please fill in the following details:

  • First Name: Enter the user's first name (e.g., John).
  • Last Name: Enter the user's last name (e.g., Doe).
  • Email: Enter the user's email address. This will be used for communication and login purposes. Ensure that the email is in the correct format (e.g., example@mail.com).
  • Phone Number: Enter the user's phone number. This will be used for contact purposes and should be in a valid format (e.g., 123-456-7890).
  • Role Name: Select the role that this user will have. The available roles are predefined in the system, and you must choose one (e.g., Admin, Manager, etc.).
  • Register User Button: After filling out the form, click the Register User button to save the new user.

Important Notes:

  • Ensure that all fields are filled in correctly before submitting the form.
  • If any error occurs during registration, an error message will appear on the screen.
  • If registration is successful, a success message will be displayed, and the new user will be registered.
