Help - Item Definition Form

This form is used to define inventory items that will be used in various transactions throughout the system.

  • Item Name: Name of the inventory item (e.g., Sugar, Rice).
  • Category: Category the item belongs to (e.g., Food, Beverages).
  • Unit: Unit of measurement (e.g., Kg, Litre).
  • Reorder Level: Minimum quantity before stock is considered low.
