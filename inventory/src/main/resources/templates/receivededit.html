Help Information

Use this form to edit the details of an item you received into inventory.

  • Item Name, Order ID, and Unit are read-only.
  • Update the Quantity Received if needed.
  • Update the Expiry Date if the item has an expiry.
  • The Edited Date is automatically set to today’s date.
  • Click Update to save changes.
