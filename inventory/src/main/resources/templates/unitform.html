Help - Unit Definition

This form allows you to define new units of measurement for the inventory system. Follow these steps:

  • Unit Name: Enter the name of the unit (e.g., Kilogram, Liter, etc.). This will represent the unit used to measure the items in the inventory.
  • Abbreviation: Enter an abbreviation for the unit (e.g., kg for Kilogram, l for Liter). This will be used in reports and in the user interface to make the unit more compact.
  • Save Unit Button: After filling in the details, click the Save Unit button to save the new unit of measurement.

Notes:

  • If you need to exit the form without saving, click the Exit button to return to the previous page.
