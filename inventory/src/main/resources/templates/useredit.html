Help - User Edit

This form allows you to edit the details of an existing user. Follow the steps below:

  • User ID: The user's ID is automatically displayed and cannot be edited. It is used to uniquely identify the user in the system.
  • First Name: Update the user's first name. Ensure that it is the correct name (e.g., John).
  • Last Name: Update the user's last name. Ensure that it is the correct name (e.g., Doe).
  • Email: Update the user's email address. Ensure the email format is valid (e.g., example@mail.com).
  • Phone Number: Update the user's phone number. Ensure the format is correct (e.g., 123-456-7890).
  • Role Name: Update the user's role from the dropdown menu. Choose the appropriate role (e.g., Admin, Manager) from the available options.
  • Update User Button: After making changes, click the Update User button to save the updated details.

Important Notes:

  • All fields are required to be updated before submitting the form.
  • After submission, a success or error message will appear based on the result of the update.
  • If the user’s information is successfully updated, the changes will be reflected in the system immediately.
