Help - Supplier Item Linkage

This form allows you to link items to a supplier. Follow these instructions carefully:

  • Supplier Name: Select the supplier from the dropdown list. The suppliers available are based on the current data.
  • Item Name: After selecting a supplier, choose the item that you want to link to that supplier from the dropdown list of available items.
  • Save Linkage Button: After selecting both the supplier and the item, click the Save Linkage button to save the relationship.

Notes:

  • If you need to exit the form without saving, click the Exit button.
  • In the table below, you can see the existing linkages between suppliers and items. You can edit or delete a linkage as needed.
  • If you want to delete an existing linkage, click the Delete button. Please confirm the deletion when prompted.
