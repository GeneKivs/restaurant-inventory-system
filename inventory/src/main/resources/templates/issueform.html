Help - Issued Items

This form is used to record items that have been issued from the inventory. Please follow the instructions below:

  • Item Name: Select the item you want to issue. The unit will automatically populate.
  • Quantity: Enter the number of units you are issuing.
  • Unit: This shows the unit of measurement for the selected item (e.g., pieces, kilograms). It is read-only.
  • Issue Date: Displays the date of issuing. It is automatically filled with today’s date and is read-only.
  • Record Issued Items: After filling in the details, click this button to save the issued item into the system.

Notes:

  • Make sure the selected item and issued quantity are correct to maintain accurate inventory records.
  • If an item is missing from the list, ensure it has been defined in the inventory items first.
